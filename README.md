# Site Spatiu
Proiect: Calea Lactee
Acest proiect reprezintă un site web simplu, construit în HTML și CSS, dedicat prezentării informațiilor despre Spațiul Cosmic și corpurile cerești.A fost realizat pentru proba de atestat la informatică.

📝 Descriere
Proiectul urmărește să combine elemente de design atrăgătoare, specifice tematicii spațiale (culori închise, elemente flotante, imagini stelare), cu o structură web clară.

🌌 Obiectivele Proiectului
Structurare HTML: Crearea unei structuri semantice cu secțiuni clare tip <header> <footer> etc
Stilizare CSS (Estetica Spațiului):

Utilizarea de fundaluri întunecate (negru, bleumarin) și culori de accent luminoase.

Aplicarea tehnicilor de layout (Flexbox/Grid) pentru aranjarea elementelor (ex: galeria de planete).

Efecte de tranziție/hover pentru a simula mișcarea sau lumina.

⚙️ Tehnologii Utilizate
HTML5: Pentru structura paginii și conținutul informațional.

CSS3: Pentru stilizare, layout și aspectul vizual de inspirație cosmică.
